Brothers Poultry Farm V3
========================

KIVABE UPLOAD KORBE
1. Zip extract koro.
2. GitHub repo (Brothers_Poultry_Farm-3.9) te ei file-gulo upload koro, purano file replace kore:
     index.html, manifest.json, service-worker.js,
     icon-192.png, icon-512.png, icon-maskable-512.png
3. Commit koro, 1-2 minute opekkha koro.

PHONE-E INSTALL
1. Purano shortcut / purano installed app delete koro.
2. Chrome-e site khulo, 2-3 sec opekkha kore ekbar refresh koro.
3. Chrome menu (3 dot) -> "Install app" dao.
   Ekhon "This app cannot be installed" ar ashbe na, app nijer icon ar nijer window-e khulbe.

OFFLINE
- Ekbar internet diye app khule dekho, tarpor net off kore khulle kaj korbe.

EKHAN THEKE BAD DEWA HOYECHE
- signing.keystore, signing-key-info.txt: eta Play Store build-er private key, GitHub-e upload korbe na.
- assetlinks.json: shudhu Play Store (TWA) er jonno, Chrome install-er jonno dorkar nei.
